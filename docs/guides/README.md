# Guides utilisateurs

Un guide d'une page par rôle, rédigé en S7 (avant la répétition générale) :

- `guide-participant.md` — créer son compte, choisir ses activités, afficher son QR
- `guide-distributeur.md` — se connecter, choisir l'activité, scanner, validation manuelle, que faire si le réseau tombe
- `guide-admin.md` — statistiques, liste des participants, inscription sur place, annonces
- `guide-admin-superieur.md` — activités, affectations, comptes du personnel, régénération de QR, journal

Règle : des phrases courtes et des captures d'écran de la préproduction (jamais de données réelles).
